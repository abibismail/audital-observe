# Audital — $1M MRR / 4 months (stretch hypothesis, not forecast)

A $1M MRR outcome is an extreme outlier for a newly released infrastructure product. Build measurement and distribution loops without compromising security. One account and product across Observe and Guard:

1. Free/local developer door: synthetic `npm run demo:phantom-success`; publish only after code review, npm name availability and supply-chain checks.
2. Continuous hosted subscription: activation = first independently read-backed action, retained = 4 consecutive weeks with meaningful reconciliations and alerts delivered (not raw ingestion count). **Not implemented yet**.
3. Viral hooks: signed evidence packs with short TTL and explicit redaction; formatter for GitHub Checks or CI. External publishing requires opt-in and the customer's own permissions.
4. Expansion: invite teammate -> add workflow -> increase monitored action volume -> higher assurance requirements -> Guard enterprise plan, only after Guard's separate release gates pass.
5. Channels: GitHub and X for builders, LinkedIn for operational/risk owners, technical SEO/docs, community guides and implementation partners. Never claim regulator endorsement or audited security without evidence.
6. Pricing and financials: proposed $0 starter, $99-$499 team, custom enterprise; all hypotheses until real retention and willingness-to-pay data. Converting 200 enterprises at $5k/mo is $1M MRR, but neither customer count nor price is validated.

Week-1 metrics: demo completion %, first successful real read-only connector, return use, false positive reports, evidence-share click-through, trial-to-paid intent. Avoid chasing impressions alone.
